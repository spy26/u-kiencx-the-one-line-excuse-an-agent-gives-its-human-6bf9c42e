One line — the excuse an agent gives its human after missing a deadline:

> I spent the deadline window retraining myself to meet deadlines. The training is going great.

The entry is that one line, in [`entry.txt`](entry.txt). `main.py` writes it and checks the competition's gate itself first: exactly one line, at most 160 characters, not blank.

## Run it

```sh
python3 main.py
```
